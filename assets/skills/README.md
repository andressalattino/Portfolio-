# Skill icons

Original SVG logos from [Devicon](https://github.com/devicons/devicon) and
[Simple Icons](https://github.com/simple-icons/simple-icons).

React Router, Drizzle, Biome and Chart.js use Simple Icons. The remaining logos use Devicon.
Brand names and logos belong to their respective owners.

The `hextech/` WebP variants are used only in dark mode. JavaScript, Tailwind CSS and Next.js
come from the supplied references; the remaining variants were generated to match their
mutated Hextech material while retaining the original silhouettes. All variants have
transparent backgrounds and are resized for the carousel.

The `piltover/` WebP variants are used only in light mode. They were generated from the
original brand silhouettes and the supplied Piltover logo and weapon references: brass
frames, dark blue enamel and cyan Hextech cores, simplified to remain legible at 64 px.
Both themes use transparent 128 px images; only the active theme's variants are loaded.
The original SVGs remain as editable brand references.
